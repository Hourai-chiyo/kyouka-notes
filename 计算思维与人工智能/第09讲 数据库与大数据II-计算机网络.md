# Part A 数据库与大数据 II：SQL

## 1. 由关系模型到结构化数据库语言 SQL

### 1.1 SQL 的定位

> **SQL（Structured Query Language）**：数据库系统的标准语言，可以定义数据库、操纵数据库和进行数据库控制。

SQL 主要由 9 个引导词构成：

| 类别 | 引导词 | 作用 |
|---|---|---|
| **DDL**（数据定义语言） | `Create`（建立）、`Alter`（修改）、`Drop`（撤消） | 定义 Database、Table、View、Index |
| **DML**（数据操纵语言） | `Insert`（插入）、`Update`（更新）、`Delete`（删除）、`Select`（查询） | 增删改查、连接查询、模糊查询、分组查询、嵌套查询、聚集操作 |
| **DCL**（数据控制语言） | `Grant`（授权）、`Revoke`（撤消授权） | 安全性控制 |

> `[补充]` SQL 是**声明式**语言：你描述“要什么”，而不是“怎么一步步做”。具体怎么执行由 DBMS 的查询优化器决定。

### 1.2 SQL 与关系代数的对应

关系代数：

$$
\Pi_{\text{列名},\ldots,\text{列名}}
\left(
\sigma_{\text{检索条件}}(\text{表名}_1 \times \text{表名}_2 \times \cdots)
\right)
$$

SQL：

```sql
Select 列名 [, 列名] ...
From   表名1 [, 表名2] ...
[Where 检索条件];
```

语义：

> 将 `From` 后面的所有表串接起来，检索出满足“检索条件”的元组，并按给定的列名及顺序进行投影显示。

即：

```
SELECT 列名  ≈ 投影 Π
WHERE 条件   ≈ 选择 σ
FROM 多表    ≈ 笛卡尔积 ×（再用 WHERE 中的连接条件筛选）
```

### 1.3 创建数据库与表（DDL）

创建课程学习数据库 `SCT`：

```sql
Create Database SCT;
```

定义学生表 `Student`：

```sql
Create Table Student (
    S#     char(8)  not null,
    Sname  char(10),
    Ssex   char(2),
    Sage   integer,
    D#     char(2),
    Sclass char(6)
);
```

定义课程表 `Course`：

```sql
Create Table Course (
    C#      char(3),
    Cname   char(12),
    Chours  integer,
    Credit  float(1),
    T#      char(3)
);
```

一般语法：

```sql
create table 表名 (
    列名 数据类型 [not null]
    [, 列名 数据类型, ...]
);
```

> `[补充]` `not null` 是完整性约束：该列不允许为空。实际数据库还会定义主键（`primary key`）、外键（`foreign key`）、唯一性（`unique`）等约束。

### 1.4 插入数据（DML）

```sql
Insert Into Student
Values ('98030101', '张三', '男', 20, '03', '980301');

Insert Into Student (S#, Sname, Ssex, Sage, D#, Sclass)
Values ('98030102', '张四', '女', 20, '03', '980301');
```

规则：

- 如果省略列名，`Values` 中的值必须与表定义/存储的列顺序一致；
- 如果给出列名，`Values` 中的值必须与语句中列名的顺序一致。

```sql
Insert Into Course
Values ('001', '数据库', 40, 6, '001');

Insert Into Course (Cname, C#, Credit, Chours, T#)
Values ('数据库', '001', 6, 40, '001');
```

> `[补充]` 字符串用单引号；数值直接写；日期等类型按数据库约定书写。生产环境中更推荐显式列出列名，避免表结构变化导致插入失败。

## 2. SQL-SELECT 之简单使用

### 2.1 基本语法

```sql
Select 列名 [[, 列名] ...]
From   表名
[Where 检索条件];
```

语义：从表中查询满足条件的元组，并按给定列名及顺序投影显示。

### 2.2 查询所有列

```sql
Select S#, Sname, Ssex, Sage, Sclass, D#
From Student;

-- 投影所有列可以简写为 *
Select * From Student;
```

### 2.3 投影并调整列顺序

```sql
-- 检索所有年龄小于 19 岁的学生的年龄及姓名
Select Sage, Sname
From Student
Where Sage < 19;
```

投影的列可以重新排列；`Where` 只筛选行，不改变列。

### 2.4 检索条件：OR、AND

```sql
-- 或者学过 001 号课程，或者学过 002 号课程的学生的学号
Select S# From SC
Where C# = '001' OR C# = '002';
```

**课堂练习**：

```sql
Select S# From SC
Where C# = '001' AND C# = '002';
```

结果是？

- 同一行不可能同时满足 `C#='001'` 和 `C#='002'`；
- 所以结果为空；
- 答案：**D（空）**。

> 要查“既学 001 又学 002”的学生，必须用自连接或子查询，不能在同一行上用 AND。

### 2.5 去重：DISTINCT

```sql
-- 检索成绩大于 80 分的所有学号（可能重复）
Select S#
From SC
Where Score > 80;

-- 去掉重复元组
Select DISTINCT S#
From SC
Where Score > 80;
```

表和关系的细微差别：

- **表（Table）**：允许有重复元组；
- **关系（Relation）**：不允许重复元组；
- SQL 查询结果默认允许重复，需要 `DISTINCT` 去重。

### 2.6 排序：ORDER BY

```sql
Order By 列名 [asc | desc]
```

- `asc` 或省略：升序；
- `desc`：降序。

```sql
-- 按学号由小到大显示所有学生的学号及姓名
Select S#, Sname From Student
Order By S# ASC;

-- 检索 002 号课大于 80 分的所有同学学号，按成绩由高到低
Select S# From SC
Where C# = '002' and Score > 80
Order By Score DESC;
```

### 2.7 模糊查询：LIKE

```sql
列名 [not] like "字符串"
```

通配符：

| 符号 | 含义 |
|---|---|
| `%` | 匹配零个或多个字符 |
| `_` | 匹配任意单个字符 |
| `\` | 转义字符，去掉特殊字符的特定含义 |

例：

```sql
-- 所有姓张的学生
Select S#, Sname From Student
Where Sname Like '张%';

-- 名字为“张某某”（张 + 两个字）的学生
Select Sname From Student
Where Sname Like '张__';

-- 名字不姓张的学生
Select Sname From Student
Where Sname Not Like '张%';
```

**课堂练习**：`WHERE 条件中出现 LIKE '_A%'`，哪个结果可以被检索出来？

- A `BAI`：第 1 个字符 B，第 2 个字符 A，后面任意 → **匹配**；
- B `AILI`：第 1 个字符 A，第 2 个字符 I → 不匹配；
- C `BBA`：第 2 个字符 B → 不匹配；
- D `CCA`：第 2 个字符 C → 不匹配。

答案：**A（BAI）**。

### 2.8 简单查询练习

**练习**：检索“所有年龄小于等于 19 岁的学生的年龄及姓名”，正确的是？

- A 只投影了 `Sname`，缺少年龄；
- B `Select Sage, Sname From Student Where Sage <= 19;` → **正确**；
- C 投影了所有列，不符合“年龄及姓名”；
- D 缺少 `Where` 条件。

答案：**B**。

### 2.9 简单查询小结

```sql
SELECT ... FROM ... WHERE ...
SELECT DISTINCT ... FROM ... WHERE ...
SELECT ... FROM ... WHERE ... ORDER BY ...
SELECT ... FROM ... WHERE ... LIKE ...
```

## 3. SQL-SELECT 之多表联合操作

### 3.1 多表查询的基本形式

```sql
Select 列名 [, 列名] ...
From   表名1, 表名2, ...
Where  检索条件;
```

等价于：

$$
\Pi_{\text{列名},\ldots}
\left(
\sigma_{\text{检索条件}}(\text{表名}_1 \times \text{表名}_2 \times \cdots)
\right)
$$

**关键**：检索条件中必须包含**连接条件**，否则得到的是笛卡尔积（所有组合）。

### 3.2 二表连接

```sql
-- 按 001 号课成绩由高到低显示所有学生的姓名
Select Sname
From Student, SC
Where Student.S# = SC.S# and SC.C# = '001'
Order By Score DESC;
```

- `Student.S# = SC.S#` 是连接条件；
- 两个表有同名列时，必须用 `表名.属性名` 限定。

### 3.3 三表连接

```sql
-- 按“数据库”课程成绩由高到低显示所有同学姓名
Select Sname
From Student, SC, Course
Where Student.S# = SC.S#
  and SC.C# = Course.C#
  and Cname = '数据库'
Order By Score DESC;
```

三张表通过 `S#` 和 `C#` 连接起来。

### 3.4 表与列的别名

```sql
Select 列名 as 列别名 [, 列名 as 列别名] ...
From   表名1 as 表别名1 [, 表名2 as 表别名2] ...
Where  检索条件;
```

`as` 可以省略。

例：求有薪水差额（差额 > 0）的任意两位教师：

```sql
Select T1.Tname as Teacher1, T2.Tname as Teacher2
From Teacher T1, Teacher T2
Where T1.Salary > T2.Salary;
```

例：求年龄有差异的任意两位同学：

```sql
Select S1.Sname as Stud1, S2.Sname as Stud2
From Student S1, Student S2
Where S1.Sage > S2.Sage;
```

### 3.5 表与自身连接

求既学过 `C01` 又学过 `C02` 的学生学号：

```sql
Select SC1.S#
From SC SC1, SC SC2
Where SC1.S# = SC2.S#
  and SC1.C# = 'C01'
  and SC2.C# = 'C02';
```

求 `C01` 成绩比 `C02` 成绩高的学生学号：

```sql
Select SC1.S#
From SC SC1, SC SC2
Where SC1.S# = SC2.S#
  and SC1.C# = 'C01'
  and SC2.C# = 'C02'
  and SC1.Score > SC2.Score;
```

> `[补充]` 自连接的本质：把同一张表“复制”成两份，分别代表两种角色（如 C01 的成绩和 C02 的成绩），再按学号连接。

### 3.6 嵌套子查询：IN

```sql
表达式 [not] in (子查询)
```

语义：判断表达式的值是否在子查询的结果中。

例：选修了 001 号课程的学生的学号和姓名：

```sql
Select S#, Sname From Student
Where S# in (Select S# From SC Where C# = '001');
```

例：既学过 001 又学过 002 的学生学号：

```sql
Select S# From SC
Where C# = '001'
  and S# in (Select S# From SC Where C# = '002');
```

例：没学过李明老师讲授课程的所有学生姓名：

```sql
Select Sname From Student
Where S# not in (
    Select S# From SC, Course C, Teacher T
    Where T.Tname = '李明'
      and SC.C# = C.C#
      and T.T# = C.T#
);
```

> 注意：这个写法查询的是“**没学过李明任何一门课**”的学生。若写成 `T.Tname <> '李明'` 再连接，会得到“学过其他老师课程”的学生，逻辑错误。

### 3.7 非相关子查询 vs. 相关子查询

**非相关子查询**：内层查询独立进行，不涉及外层查询的信息。

```sql
Select Sname
From Student
Where S# not in (
    Select S#
    From SC, Course C, Teacher T
    Where T.Tname = '李明'
      and SC.C# = C.C#
      and T.T# = C.T#
);
```

内层可以单独执行，结果是一个学号集合。

**相关子查询**：内层查询需要依靠外层的某些参量作为限定条件。

```sql
Select Sname
From Student Stud
Where S# in (
    Select S#
    From SC
    Where S# = Stud.S# and C# = '001'
);
```

- 内层引用了外层的别名 `Stud.S#`；
- 外层每取一个学生，内层都要重新执行一次；
- 只能由外层向内层传递参数，不能反过来（变量作用域原则）。

> `[补充]` 相关子查询通常较慢，因为外层每行都要执行一次内层；实际 DBMS 会做优化（如改写为连接）。理解概念比死记性能更重要。

### 3.8 多表查询练习

**练习 1**：求既学过 001 又学过 002 的学生学号，正确的是？

- A `Where C#='001' AND C#='002'` —— 同一行不可能，错；
- B 自连接 `SC S1, SC S2`，`S1.S#=S2.S#`，`S1.C#='001'`，`S2.C#='002'` —— **正确**；
- C 自连接但缺少 `S1.S#=S2.S#` —— 会得到所有学生组合，错；
- D 同一行 AND —— 错。

答案：**B**。

**练习 2**：求既学过 002 又学过 003 的学生学号，**不正确**的是？

- A `Where C#='002' AND C#='003'` —— **不正确**（同一行不可能）；
- B `INTERSECT` —— 正确；
- C `IN` 子查询 —— 正确；
- D 自连接 —— 正确。

答案：**A**。

**练习 3**：阅读 SQL：

```sql
Select Sname From Student
Where S# NOT IN (
    Select S# From SC, Course C, Teacher T
    Where T.T# = '李明'
      and SC.C# = C.C#
      and T.T# = C.T#
);
```

（注：幻灯片中 `T.T# = '李明'` 应为 `T.Tname = '李明'`。）

含义：列出**没学过李明老师讲授任一课程**的学生姓名。

答案：**D**。

**练习 4**：阅读 SQL：

```sql
Select S# From SC SC1
Where SC1.C# = 'C01'
  AND S# IN (
      Select S# From SC SC2
      Where SC2.C# = 'C02'
        AND SC1.S# = SC2.S# 
        AND SC1.Score > SC2.Score
  );
```

含义：**C01 课程成绩比 C02 课程成绩高的所有学生的学号**。

答案：**B**。

**练习 5**：已知 SC 数据，执行：

```sql
SELECT S# FROM SC WHERE C# = 'C1' AND C# = 'C3'
```

- 同一行不可能同时是 C1 和 C3；
- 结果为空；
- 答案：**E（前述都不正确）**。

## 4. SQL-SELECT 之分组聚集操作

### 4.1 结果计算

`Select` 子句可以包含计算表达式或聚集函数：

```sql
Select 列名 | expr | agfunc(列名) ...
From   表名1 [, 表名2 ...]
[Where 检索条件];
```

例：求有差额的任意两位教师的薪水差额：

```sql
Select T1.Tname as TR1, T2.Tname as TR2, T1.Salary - T2.Salary
From Teacher T1, Teacher T2
Where T1.Salary > T2.Salary;
```

### 4.2 五个聚集函数

| 函数 | 参数类型 | 结果 | 含义 |
|---|---|---|---|
| `COUNT` | 任意（可为 `*`） | 数值 | 计数 |
| `SUM` | 数值 | 数值 | 求和 |
| `AVG` | 数值 | 数值 | 平均 |
| `MAX` | 字符或数值 | 与参数同类型 | 最大值 |
| `MIN` | 字符或数值 | 与参数同类型 | 最小值 |

例：

```sql
-- 教师工资总额
Select Sum(Salary) From Teacher;

-- 计算机系教师工资总额
Select Sum(Salary) From Teacher T, Dept
Where Dept.Dname = '计算机' and Dept.D# = T.D#;

-- 数据库课程的平均成绩
Select AVG(Score) From Course C, SC
Where C.Cname = '数据库' and C.C# = SC.C#;
```

### 4.3 分组：GROUP BY

> 分组：把具有相同条件值的元组划到一个组（集合）中，再对每个组做聚集运算。

语法：

```sql
Select 列名 | expr | agfunc(列名) ...
From   表名1 [, 表名2 ...]
[Where 检索条件]
[Group By 分组条件];
```

例：

```sql
-- 每个学生的平均成绩
Select S#, AVG(Score) From SC
Group By S#;

-- 每门课程的平均成绩
Select C#, AVG(Score) From SC
Group By C#;
```

> 分组后，`Select` 列表里只能出现分组属性和聚集函数（标准 SQL 的规则）。

### 4.4 分组过滤：HAVING

> `WHERE` 过滤**行**，`HAVING` 过滤**组**。

语法：

```sql
Select ...
From ...
[Where 检索条件]
[Group By 分组条件 [Having 分组过滤条件]];
```

例：求不及格课程超过两门的同学学号：

```sql
Select S# From SC
Where Score < 60
Group By S# 
Having Count(*) > 2;
```

例：求有 10 人以上不及格的课程号：

```sql
Select C# From SC
Where Score < 60
Group By C#
Having Count(*) > 10;
```

> 注意：`HAVING` 必须与 `GROUP BY` 一起使用；它检查的是每个分组，而不是每一行。

### 4.5 一个易错例子

求“有两门以上不及格课程的同学的学号及其**平均成绩**”：

```sql
-- 错误写法：平均成绩只对不及格课程求平均
Select S#, Avg(Score) From SC
Where Score < 60
Group By S# Having Count(*) > 2;
```

这个写法先过滤掉及格课程，再分组，所以 `AVG(Score)` 是不及格课程的平均分，不是该学生所有课程的平均分。

正确写法：先用子查询找出“不及格课程 > 2 门”的学号，再在外层对全部成绩分组求平均：

```sql
Select S#, AVG(Score) From SC
Where S# in (
    Select S# From SC
    Where Score < 60
    Group By S# Having Count(*) > 2
)
Group By S#;
```

> `[补充]` 这是 SQL 中“**先筛选实体，再计算整体指标**”的典型模式。`WHERE` 在分组前生效，容易误伤后续计算。

### 4.6 分组练习

**练习 1**：

```sql
SELECT C# FROM SC
WHERE Score < 60
GROUP BY C#
HAVING Count(*) > 2;
```

含义：有 **2 人以上不及格**的**课号**。

答案：**D**。

**练习 2**：

```sql
SELECT S# FROM SC
WHERE Score < 60 AND Count(*) > 2
GROUP BY S#;
```

问题：`Count(*)` 是聚集函数，不能直接出现在 `WHERE` 子句中（`WHERE` 在分组前执行）。

答案：**E（其它选项说法都不正确）**。

### 4.7 SQL 查询完整语法顺序

```sql
SELECT   [DISTINCT] 列名/表达式/聚集函数
FROM     表名 [别名], ...
[WHERE   行条件]
[GROUP BY 分组列]
[HAVING  组条件]
[ORDER BY 排序列 [ASC|DESC]];
```

执行顺序（逻辑上）：

```
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
```

> `[补充]` 记住执行顺序，就能理解为什么 `WHERE` 里不能用聚集函数、为什么 `HAVING` 能用、为什么 `SELECT` 的别名通常不能在 `WHERE` 中使用。

# Part B 计算机网络

## 5. 计算机网络基本概念

### 5.1 为什么需要计算机网络

网络改变了学习、生活、工作、娱乐方式：

```
学习、工作、生活、娱乐
        ↓
    计算机网络
```

人类生存空间从陆、海、空、天扩展到“网”。

### 5.2 计算机网络的定义

> **计算机网络**：互连的、自治的计算机集合。

两个关键词：

- **自治**：计算机之间无主从关系；
- **互连**：计算机之间可以互联互通，通过通信链路连接。

问题：距离远、数量大，如何保证互连？

- 如果每两台主机之间都拉一条链路，需要 $N(N-1)/2$ 条链路 → **N² 链路问题**；
- 解决方案：使用**交换设备**和**交换网络**，动态分配传输资源。

### 5.3 交换设备

| 设备 | 工作层次 | 作用 |
|---|---|---|
| 集线器（Hub） | 物理层 | 物理上集中连接，广播式转发 |
| 交换机（Switch） | 链路层 | 按 MAC 地址转发 |
| 路由器（Router） | 网络层 | 按 IP 地址路由转发 |

交换设备有多个端口，连接多台主机/网络，实现“动态分配传输资源”。

### 5.4 计算机网络的分类

#### 按覆盖范围

| 类型 | 全称 | 覆盖范围 |
|---|---|---|
| PAN | 个域网 | 个人设备连接（蓝牙等） |
| LAN | 局域网 | 办公室、学校等较小范围 |
| MAN | 城域网 | 整个城市或城市区域 |
| WAN | 广域网 | 利用公共通信线路连接的大范围网络 |

还有移动网络、家庭网络、机构网络（校园网）、区域 ISP、全球 ISP 等。

**课堂练习**：下列不属于按覆盖范围分类的是？

- A 局域网；
- B 广域网；
- C 城域网；
- D 总线网。

答案：**D（总线网，属于按拓扑结构分类）**。

#### 按拓扑结构

- 星形拓扑；
- 总线形拓扑；
- 环形拓扑；
- 网状拓扑；
- 树形拓扑；
- 混合拓扑。

不同拓扑的可靠性、扩展性、成本不同：

- 星形：中心节点故障影响大，但管理简单；
- 总线：共享信道，冲突多；
- 环形：令牌/顺序访问；
- 网状：冗余路径多，可靠性高，成本高。

### 5.5 网络协议

仅有硬件连接，网络不能顺畅运行；还需要**协议**。

> **网络协议（network protocol）**：为进行网络中的数据交换而建立的规则、标准或约定。

协议规定通信实体之间交换的消息的：

| 要素 | 含义 |
|---|---|
| **语法（Syntax）** | 数据与控制信息的结构或格式、信号电平 |
| **语义（Semantics）** | 需要发出何种控制信息、完成何种动作、做出何种响应、差错控制 |
| **时序（Timing）** | 事件顺序、速度匹配 |

**课堂多选**：网络协议包含以下哪些内容？

- A 语法；
- B 语义；
- C 同步（时序）；
- D 异步。

答案：**A、B、C**。

### 5.6 计算机网络的结构

```
网络边缘：主机、网络应用
        ↓
接入网络、物理介质：有线/无线通信链路
        ↓
网络核心：互联的路由器（分组转发设备）、网络之网络
```

- **网络边缘**：用户直接使用的主机和应用程序；
- **接入网**：把边缘设备接入核心网（家庭宽带、Wi-Fi、蜂窝网络等）；
- **网络核心**：由路由器和链路组成的骨干网络。

## 6. 计算机网络性能

### 6.1 速率与带宽

**速率（data rate / bit rate）**：

- 单位时间（秒）传输的信息（比特）量；
- 计算机网络中最重要的性能指标；
- 单位：b/s（bps）、kb/s、Mb/s、Gb/s；
- $k=10^3$，$M=10^6$，$G=10^9$。

**带宽（bandwidth）**：

- 原本指信号具有的频带宽度，即最高频率与最低频率之差，单位 Hz；
- 网络的“带宽”通常指数字信道能传送的“最高数据率”，单位 b/s。

### 6.2 延迟（时延）

分组从源到目的地经历四种延迟：

| 延迟 | 含义 |
|---|---|
| $d_{proc}$ | 结点处理延迟（nodal processing delay） |
| $d_{queue}$ | 排队延迟（queueing delay） |
| $d_{trans}$ | 传输延迟（transmission delay） |
| $d_{prop}$ | 传播延迟（propagation delay） |

总延迟：

$$
d_{nodal} = d_{proc} + d_{queue} + d_{trans} + d_{prop}
$$

> `[补充]` 传输延迟是“把比特推上链路”的时间（与分组长度、链路速率有关）；传播延迟是“信号在介质中传播”的时间（与距离、介质速度有关）。二者常被混淆。

## 7. 计算机网络体系结构

### 7.1 为什么需要体系结构

网络系统非常复杂，涉及主机、路由器、链路、应用、协议、硬件、软件……

需要一个**分层结构**来有效描述网络：

> **网络体系结构**：从功能上描述计算机网络结构，是各层及其协议的集合。

- 分层结构；
- 每层遵循某个/些网络协议完成本层功能；
- 体系结构是抽象的。

### 7.2 生活中的类比：邮政网络

| 邮政网络 | Internet |
|---|---|
| 发件人 & 收件人 | 发送者 & 接收者 |
| 聚集点 & 发送点 | 端口号 |
| 发送邮局 & 接收邮局 | 发送 IP & 接收 IP |
| 邮路发送/接收站点 | 链路层地址（MAC 地址/物理地址） |

邮政网络的分层处理（收件、分拣、运输、投递）与网络协议栈的分层处理非常相似。

### 7.3 OSI 参考模型

> **OSI（Open Systems Interconnection）参考模型**：国际标准化组织（ISO）于 1984 年提出的分层网络体系结构模型。

目的：

- 支持异构网络系统的互联互通；
- 异构系统互连的国际标准；
- 理解网络通信过程的最佳学习工具（理论模型）。

**理论成功，市场失败**。

7 层（从下到上）：

| 层 | 名称 | 主要功能 |
|---|---|---|
| 7 | 应用层（Application） | 网络应用 |
| 6 | 表示层（Presentation） | 数据格式、加密、压缩 |
| 5 | 会话层（Session） | 会话管理 |
| 4 | 传输层（Transport） | 端到端传输 |
| 3 | 网络层（Network） | 路由与转发 |
| 2 | 数据链路层（Data Link） | 相邻节点传输 |
| 1 | 物理层（Physical） | 比特传输 |

### 7.4 TCP/IP 参考模型

四层：

```
应用层：HTTP、SMTP、DNS、RTP ...
运输层：TCP、UDP
网际层：IP
网络接口层：网络接口1、2、3 ...
```

核心思想：

> **IP over Everything**：IP 可以应用到各式各样的网络上。

### 7.5 五层参考模型

综合 OSI 和 TCP/IP 的优点：

| 层 | 功能 | 典型协议 |
|---|---|---|
| 应用层 | 支持各种网络应用 | FTP、SMTP、HTTP |
| 传输层 | 进程—进程的数据传输 | TCP、UDP |
| 网络层 | 源主机到目的主机的数据分组路由与转发 | IP、路由协议 |
| 数据链路层 | 相邻网络元素（主机、交换机、路由器）的数据传输 | Ethernet、802.11（WiFi）、PPP |
| 物理层 | 比特传输 | 硬件实现 |

**课堂多选**：5 层参考模型与 OSI 参考模型相比，缺少的层次是？

- A 表示层；
- B 会话层；
- C 传输层；
- D 数据链路层。

答案：**A、B**（5 层模型把表示层和会话层的功能并入应用层）。

### 7.6 IP 地址

**IP（Internet Protocol）**：

- IPv4 和 IPv6；
- IPv4 地址是 32 位地址，通常用 4 个字节的十进制表示（点分十进制）；
- 结构：网络号（NetID，高位）+ 主机号（HostID，低位）；
- 网络号和主机号有不同的划分方案（子网掩码/CIDR）。

例：

```
二进制：11010100 01110110 11100000 00000010
点分十进制：202.118.224.2
```

IPv6：

- 128 位地址；
- 可识别 $2^{128}$ 个设备。

> `[补充]` IPv4 地址耗尽推动了 IPv6 的部署；NAT、CIDR 等技术也在延长 IPv4 的寿命。

### 7.7 DNS：域名系统

**域名层次结构**：

```
根
├── 顶级域名：aero ... com net org edu gov ... cn rs ...
│     ├── 二级域名：amazon ... sina google hr ... edu com
│     │     ├── 三级域名：www ... mail pku ... hit
│     │     │     └── 四级域名：www ... mail
```

**DNS（Domain Name System）**：

- Internet 上以符号命名的计算机，与 IP 地址有一一对应关系；
- 由**域名服务器**负责转换；
- 域名服务器分布于世界各地，管理各自范畴的网络。

例：

```
域名：BBS.HIT.EDU.CN
IP：202.118.224.2
```

**课堂练习**：DNS 的主要功能是？

- A 域名到 URL 的映射；
- B 域名到 IP 地址的映射 —— **正确**；
- C 网络应用到端口号的映射；
- D IP 地址到 MAC 地址的映射（这是 ARP）。

答案：**B**。

## 8. 网络应用

### 8.1 电子邮件

```
用户 A（用户代理）→ 邮件服务器 A → SMTP → 邮件服务器 C → 用户 B/C（用户代理）
```

- 发送邮件使用 **SMTP**（Simple Mail Transfer Protocol）；
- 读取邮件使用邮件读取协议（如 POP3、IMAP）；
- 用户代理负责编辑、发送、接收、显示邮件。

### 8.2 文件传输：FTP

```
FTP 客户 ── 控制连接 21 ── FTP 服务器
        └─ 数据连接 20 ── 文件系统
```

- 控制连接端口 21；
- 数据连接端口 20；
- 客户与服务器之间传输文件。

> `[补充]` FTP 使用两条连接：控制连接传命令，数据连接传文件内容；这与 HTTP 的单连接不同。

### 8.3 WWW 与 HTTP

**WWW（World Wide Web）**：

- 应用层协议：**HTTP**（HyperText Transfer Protocol，超文本传输协议）；
- C/S 结构：
  - 客户端（Browser）：请求、接收、展示 Web 对象；
  - 服务器（Web Server）：响应请求、发送对象、存储 Web 对象；
- HTTP 使用 **TCP** 传输服务；
- 服务器默认端口号：**80**。

HTTP 连接过程：

1. 浏览器发起到服务器的 TCP 连接；
2. 服务器接受连接；
3. 浏览器与服务器交换 HTTP 消息；
4. 关闭 TCP 连接。

### 8.4 URL：统一资源定位器

> **URL（Universal Resource Locator）**：各类文件或程序的统一地址。

三部分：

```
协议://主机名.域名.顶级域名/路径/文件名.扩展名
Protocol://host.domain.first-level-domain/path/filename.ext
```

例：

```
http://www.hit.edu.cn/
http://202.118.231.4/
ftp://ftp.hit.edu.cn/
```

**URL vs. IP 地址**：

- URL 是**资源**（文件或程序）地址；
- IP 地址是**机器**地址。

常见协议：

| 协议 | 含义 |
|---|---|
| `http://` | HTML 文件 |
| `https://` | 保密的 HTML 文件 |
| `ftp://` | FTP 网站和文件 |
| `gopher://` | Gopher 菜单和文件 |
| `news://` | 特定新闻服务器上的 UseNet 新闻组 |
| `mailto:` | 电子邮件 |
| `telnet:` | 远程登录 |

> `[补充]` 现代 Web 中 `https` 已成为默认；`gopher`、`telnet` 基本退出历史舞台。

## 9. 信息网络与标记语言

### 9.1 信息网络

因特网环境下，信息对象之间存在关联关系：

- 网页 = 文件；
- 内容 = 文本/多媒体；
- 如何描述信息对象间的关联关系？

### 9.2 超文本与超媒体

> **超文本/超媒体 = 普通文本/媒体 + 链接**。

- 技术方面：怎样实现文档之间的关联？
- 内容方面：怎样建立文档之间的关联？

例：古诗词文档之间通过链接关联，形成超文本。

### 9.3 HTML：超文本标记语言

> **HTML（HyperText Markup Language）**：一系列预定义的标记的集合。

HTML 文档由 HTML 标记和相应的文本组成；一个 HTML 文档又称一个 Web Page（网页）。

例：

```html
<HTML>
<HEAD>
<TITLE>Hello World!</TITLE>
</HEAD>
<BODY>
世界你好！
</BODY>
</HTML>
```

- `<HTML>`：HTML 文件起始标记；
- `<HEAD>...</HEAD>`：文件头；
- `<TITLE>...</TITLE>`：网页标题；
- `<BODY>...</BODY>`：主体内容；
- `</HTML>`：文件结束标记。

浏览器的作用：

```
HTML 源文件 → 浏览器（HTML 解释器）→ 网页显示
```

浏览器的主要组成：

- 主控制器；
- HTML 解释器；
- 其他可选解释器；
- 显示器驱动；
- HTTP 客户；
- 其他协议客户；
- 网络接口。

### 9.4 标记语言的本质

```
<标记>文本</标记>
```

- `<标记>`：标记的开始；
- `</标记>`：标记的结束（带 `/`）；
- 文本：待处理的对象（纯文本或多媒体）；
- 标记：描述对象某一方面的性质，由相应处理程序解析或利用。

标记可以嵌套：

```html
<标记F>
  <标记K>
    <标记M>文本</标记M>
  </标记K>
</标记F>
```

### 9.5 HTML 中的超链接

```html
<A HREF="URL">文本</A>
```

三种链接：

1. **绝对地址链接**：

```html
<A HREF="http://www.bignet.net/realcorp/products.html">Our Product</A>
```

2. **本机内相对地址链接**：

```html
<A HREF="products.html">Our Product</A>
```

3. **文档内部段节链接**：

```html
<!-- 链源锚（链接者） -->
<A HREF="#section_name">Link to another section of this document</A>

<!-- 链宿锚（被链接段节需要定义） -->
<A NAME="section_name">Beginning of new section</A>
```

### 9.6 XML：扩展标记语言

> **XML（eXtensible Markup Language）**：扩展标记语言。

HTML vs. XML：

| 维度 | HTML | XML |
|---|---|---|
| 标记 | 预定义 | 可自定义 |
| 目的 | 描述网页的显示 | 描述数据的结构和含义 |
| 严格性 | 较宽松 | 严格（标签必须闭合、嵌套正确） |
| 用途 | Web 页面 | 数据交换、配置文件、领域语言 |

XML 示例：

```xml
<book>
  <title>Foundations of DBs</title>
  <author>Abiteboul</author>
  ...
  <year>1995</year>
  <price>55</price>
  <currency>USD</currency>
</book>
```

XML 的用途：

- 基于 XML 定义新语言（一套标记的集合及其处理规则）；
- 数据交换；
- 配置文件；
- 领域专用语言。

> `[补充]` HTML 关注“怎么显示”，XML 关注“数据是什么”。HTML5 之后，HTML 也引入了更多语义化标签，但二者的设计目标仍然不同。

### 10.3 自测问题（附答案）

1. SQL 的 DDL、DML、DCL 各包含哪些语句？
   **答**：DDL：Create/Alter/Drop；DML：Insert/Update/Delete/Select；DCL：Grant/Revoke。
2. `WHERE` 和 `HAVING` 有什么区别？
   **答**：`WHERE` 在分组前过滤行；`HAVING` 在分组后过滤组，通常与 `GROUP BY` 一起使用。
3. 相关子查询和非相关子查询有什么区别？
   **答**：非相关子查询独立于外层，可单独执行；相关子查询引用外层参数，外层每行都要执行一次内层。
4. 如何查“既学 A 课又学 B 课”的学生？
   **答**：自连接（两个 SC 别名，学号相等，分别限定课程号），或用两个投影取交集/`IN` 子查询。
5. 计算机网络的定义是什么？
   **答**：互连的、自治的计算机集合。
6. 网络协议的三要素是什么？
   **答**：语法、语义、时序（同步）。
7. OSI 七层和 TCP/IP 四层分别是什么？5 层模型缺哪两层？
   **答**：OSI：物理、数据链路、网络、传输、会话、表示、应用；TCP/IP：网络接口、网际、运输、应用；5 层模型缺少表示层和会话层。
8. DNS 的作用是什么？
   **答**：把域名映射为 IP 地址。
9. HTTP、FTP、SMTP 的默认端口/用途是什么？
   **答**：HTTP 80（Web）、FTP 21 控制/20 数据（文件传输）、SMTP 25（邮件发送，幻灯片未强调端口）。
10. HTML 和 XML 有什么区别？
    **答**：HTML 使用预定义标记描述网页显示；XML 使用自定义标记描述数据结构，标签严格闭合，常用于数据交换。
